# ユニットテスト実行手順

## テスト実行

```bash
npm test
```

## 期待結果
- **テストファイル**: 10件合格
- **テスト総数**: 29件以上合格（RankingChart ストーリー3件含む）
- **失敗**: 0件

## RankingChart ストーリーテスト
- `Default` — 30社分のグラフが表示される
- `WithFewItems` — 5社分のグラフが表示される
- `Empty` — 「データがありません」が表示される

## テスト失敗時
1. `npm test` のエラー出力を確認する
2. 失敗テストのコンポーネントを修正する
3. 再実行して全件合格を確認する

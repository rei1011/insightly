# 統合テスト手順

## シナリオ 1: フィルタ連動確認

### 説明
職種・年齢フィルタを変更したとき、グラフとテーブルが同じデータで更新される。

### 手順
1. `npm run db:start` でDBを起動
2. `npm run dev` でアプリを起動
3. `http://localhost:3000/ranking` にアクセス
4. グラフとテーブルが上位30社で一致していることを確認
5. 職種フィルタを選択 → グラフとテーブルが同時に更新されることを確認
6. 年齢フィルタを入力 → グラフとテーブルが同時に更新されることを確認

### 期待結果
- グラフとテーブルの順位・会社名・数値が一致する
- フィルタ変更後もグラフが正常に再描画される

## シナリオ 2: 空データ確認

### 手順
1. 存在しない職種の組み合わせでフィルタリング
2. 「データがありません」メッセージがグラフ・テーブル両方に表示されることを確認

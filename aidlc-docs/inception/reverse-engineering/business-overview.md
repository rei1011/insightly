# ビジネス概要

## ビジネスコンテキスト図

```
+------------------+        +-------------------+
|     ユーザー      | -----> |   Insightly Web   |
| (給与情報を調べる人)|        |  (Next.js App)    |
+------------------+        +-------------------+
                                      |
                              +-------+-------+
                              |               |
                    +---------+------+  +-----+--------+
                    | 報酬一覧画面    |  | ランキング画面 |
                    | (フィルタ付き) |  | (上位30社)    |
                    +---------------+  +--------------+
                              |               |
                    +---------+---------------+
                              |
                    +---------+-------+
                    |   PostgreSQL DB  |
                    | (salary/company/ |
                    |  occupation)     |
                    +-----------------+
```

## ビジネス説明

- **ビジネス概要**: 給与データの検索・可視化サービス。ユーザーが会社・職種・年齢・年収で絞り込んで給与データを確認できる。
- **ビジネストランザクション**:
  1. **給与データ閲覧**: 条件でフィルタリングしながら給与一覧を表示・ソート
  2. **会社別平均年収ランキング表示**: 職種・年齢でフィルタした上位30社のランキングを表示

## コンポーネント別ビジネス説明

### 報酬一覧ページ (/)
- **目的**: 個別の給与データを検索・参照できる
- **責務**: フィルタ（会社名・職種・年齢・年収）の管理、ページネーション付き一覧表示

### ランキングページ (/ranking)
- **目的**: 会社ごとの平均年収をランキング形式で表示
- **責務**: 職種・年齢でフィルタした上位30社を平均年収順に表示
